# 품.꿈.힘 한자 어휘 추론 공부 v5.0.0

초등학생이 문장을 읽고, 주어진 한자를 실마리로 빈칸의 한자어를 추론하는 학습 웹앱(PWA)입니다.

## 폴더 구성

```
src/                  ← 앱 원본(이 폴더만 고치면 됩니다)
  index.html            화면 뼈대
  core_engine.js        핵심엔진 (v4.0.4 운영본 + 오류 2건만 수정)
  app/ui.js             새 화면 동작(엔진을 감싸서 화면만 바꿈)
  app/app.css           디자인
  data/questions.js     ★ 문항 목록 — 문항 추가·수정은 여기서
  data/db-builder.js    문항 → 엔진용 DB 변환(수정 불필요)
  sw.js                 오프라인 저장(수정 불필요, 버전 자동)
  manifest.json         앱 이름·아이콘
  icons/                앱 아이콘
teacher/index.html    교사용 문항 관리 페이지(PC에서 더블클릭)
tools/build.mjs       검사 + 배포용 dist/ 생성 + 단일파일 자동 생성
.github/workflows/    GitHub에 올리면 자동 배포
```

## 처음 한 번: 자동 배포 켜기

1. 지금 저장소(`hanja-edu-cb`)의 기존 파일을 지우고, 이 폴더의 내용을 **그대로** 올립니다.
   (숨김 폴더 `.github`도 함께 올라가야 합니다. 웹에서 올릴 때는 폴더째 끌어다 놓으세요.)
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. **Actions** 탭에서 "배포 (GitHub Pages)"가 초록색 ✔이 되면 끝입니다(1~2분).

주소는 그대로입니다: `https://ekoredu-maker.github.io/hanja-edu-cb/`
→ 주소가 같으므로 **학생들의 기존 학습 기록(마일리지·한자나무·오답 통계)이 그대로 이어집니다.**

## 평소 운영

| 하고 싶은 일 | 방법 |
|---|---|
| 문항 추가·수정 | `teacher/index.html`을 PC에서 열기 → 편집 → [questions.js 내려받기] → GitHub의 `src/data/questions.js`에 덮어 올리기 |
| 배포 | 파일을 올리면 자동. 따로 할 일 없음 |
| 버전 올리기 | 필요 없음(내용이 바뀌면 캐시 버전이 자동으로 바뀜). 표시 버전을 바꾸려면 `package.json`의 `version`만 수정 |
| 학생 기기 업데이트 | 앱을 열면 상단에 "새 버전이 준비됐어요 [지금 업데이트]"가 뜸 |
| 문항에 오류가 있으면 | Actions가 빨간 ✖로 멈추고, 로그에 몇 번째 문항의 무엇이 문제인지 한국어로 나옴(기존 사이트는 그대로 유지) |
| 파일 하나로 실행 | 배포 주소 뒤에 `index_singlefile.html` (빌드 때 자동 생성) |

## PC에서 미리 보기(선택)

Node.js가 설치되어 있으면:

```bash
node tools/build.mjs          # 검사 + dist/ 생성
cd dist && python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 이번 버전에서 바뀐 것 (v4.0.4 → v5.0.0)

- 화면 전체 새 디자인: 원고지·한자 연습칸(田字格)·도장 콘셉트, 휴대폰/태블릿 각각 맞춤 배치
- 홈 화면: 한자나무 그림(5단계), 다음 단계까지 남은 점수, 품·꿈·힘 단계별 진도
- 정답 화면: 도장 + 한자 풀이 + 빈칸이 채워진 문장 + 실제로 얻은 마일리지·성장점수
- 두 번 틀리면 "정답 보고 넘어가기"
- 복습 노트(틀린 낱말 / 힌트 본 낱말 / 맞힌 낱말)
- 설정: 글자 크기, 학습 기록 파일 저장·불러오기(기기 변경 대비), 앱 설치 안내, 기록 지우기
- 스마트폰·패드 맞춤: 한자 카드가 글자 수(1~4자)에 맞춰 한 줄로 배치, 폰 가로·패드 세로·패드 가로 각각 다른 배치,
  큰 글씨 설정 시 자동 2줄 배치, 정답 화면의 [다음 문제] 버튼 항상 보이기, 연속정답 표시 간소화, 두 번 탭 확대·길게 눌러 선택 방지
- 새 버전 알림, 오프라인 동작 개선, 한글 조합 중 Enter(안드로이드·아이패드 키보드) 오작동 방지, 키보드가 입력창을 가리지 않도록 보정
- 교사용 문항 관리 페이지, 자동 문항 검사, 자동 배포, 단일파일 자동 생성
- 핵심엔진(`core_engine.js`)은 운영본에서 오류 2건만 수정, 출제·보상·성장 로직은 그대로
  - 이스터 에그 문구가 어떤 입력에도 일치하지 않던 오류 수정(띄어쓰기·문장부호를 빼고 비교)
  - 나무 정보가 없는 기록의 기본 단계값 '품' → 'seed' 수정
  - 빌드 때 엔진 지문을 확인하므로, 앞으로 엔진을 직접 고치면 `node tools/build.mjs --accept-engine`으로 등록
